# suanli-h3-video 使用指南：一句话，一部片

> 你带着一个想法来——一个十秒的视觉梗、一支产品宣传片、一套批量素材。
> 说一句话，Agent 帮你租卡、生成、超分、收尾关机。768p / 5 秒成片约 **¥0.08**。

## 这是什么

把 **MiniMax H3**（开源音画一体视频模型）部署在**共绩算力**的 RTX 5090 上，封装成 Agent 可直接调用的技能（Skill）：

- **文生视频（T2V）**：一句话描述画面和声音，直接出带音频的成片
- **参考生视频（R2V）**：给一张角色/产品图，按你的文字生成对应视频
- **一键 2K**：生成的 768p 用 RTX VSR AI 超分到 2K
- **用完即停**：Agent 管理实例的启停，按秒计费，不为闲置付一分钱

## 快速开始

### 1. 准备

- 共绩算力账号（[console.suanli.cn](https://console.suanli.cn)）+ API 密钥（右上角头像 → API 密钥，选**简易模式**）
- 余额 ≥ ¥5（跑一批 8 条 768p/5s 约需 ¥1.5）

### 2. 安装技能

```
npx skills add <你的仓库地址> --skill suanli-h3-video
```

装好后把 `.env.example` 复制为 `.env`，填入 `SUANLI_TOKEN`。

### 3. 开始用

对 Agent 说：

> 用 suanli-h3-video 生成一条 5 秒视频：日出时分，热气球缓缓升起的卡帕多奇亚，金光洒满奇石林。Audio: 清晨风声与远处鸟鸣

Agent 会自动完成：查库存租 5090 → 起服务 → 等就绪 → 生成 → 下载到你本地 → **询问你是否暂停实例**。

想批量就说：

> 同样的提示词生成 6 条，768p，5 秒

想更清晰就加一句：

> 生成完全部超分到 2K

## 常用说法

| 你说 | Agent 做 |

## 提示词怎么写（写给 C 端用户）

H3 的提示词**同时描述画面和声音**，越具体越好：

```
画面：黄昏的老城屋顶，一只橘猫踩着瓦片追一片被风吹起的报纸，
      手持跟拍，暖色调，浅景深。
Audio: 风声、瓦片轻响、猫爪窸窣、远处教堂钟声
```

- 写**镜头**（跟拍/航拍/特写/慢动作）——模型听得懂
- 写**声音**（Audio: 后接环境音/音乐描述）——成片自带音轨
- 想要参考角色时给图（R2V），提示词里用 `<Picture 1>` 指代

## 常见问题

**Q：生成的视频没有声音？**
A：提示词里写 `Audio: ...`。H3 是音画一体模型，不写声音描述时可能静音。

**Q：批量跑一半断了怎么办？**
A：重新执行同样的 submit 命令，已完成的任务自动跳过（断点续跑）。

**Q：为什么不能一边生成一边超分？**
A：单卡显存放不下两个模型同时跑（27.8G + 10.5G > 32G），必须先生成完一批再统一超分。Agent 已内置这个顺序。

**Q：1080p 可以吗？**
A：32G 的 5090 跑 1080p/10s 会显存溢出。推荐 768p 生成 + VSR 超分到 2K，效果更好且更稳。

**Q：怎么最省钱？**
A：攒够一批再开实例（一次冷启动摊薄）；生成后立刻关机；短试错用 480p。

## 面向工作室的批量模式

`scripts/h3_batch.py` 支持完整流水线：

```
submit   批量提交（--prompt-file 多行 prompt / --count N 复读）
status   进度汇报
upscale  批量 2K
done     生成 manifest.json（id/prompt/seed/产物路径 对照表）
```

所有状态记在 `jobs/<时间戳>/job.json`，中断续跑、事后审计都靠它。
